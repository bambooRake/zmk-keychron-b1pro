# LalaPadGen2 → Keychron B1 Pro JIS keymap 移植方針

移植元: `C:\0_git\zmk-config-LalaPadGen2\config\lalapadgen2.keymap`
移植先: `C:\0_git\zmk-keychron-b1pro\app\boards\shields\keychron\b1\jis\keychron_b1_jis.keymap`

- - -

## 0\. 物理レイアウト前提

| 項目 | LalaPadGen2 | B1 Pro JIS |
| --- | ----------- | ---------- |
| キー数 | 60%スプリット + 親指/ナビ/マウス列 + トラックパッド | 86キー（ほぼ100%） |
| OSモード | 単一 | Mac (layer0/1) / Win (layer2/3) のデュアル |
| 専用キー | なし（FN/数字をレイヤーで実現） | ESC, F1-F12, BSPC, TAB, CAPS, INT3/INT1/NUHS, 矢印 すべて専用キー |

⇒ 60%特有のレイヤー圧縮設定（mt\_tap で1キーに2機能、親指レイヤーキー、マウスtap-dance等）は基本的にB1 Proでは不要 / 不可能。

## 1\. 移植元 LalaPadGen2 の構成

### 1-1. レイヤー

* `DEFAULT_LAYER`(0): QWERTY + HRM
* `SECONDARY_LAYER`(1): 数字+記号+F1-F12+数字行HRM
* `TERTIARY_LAYER`(2): ナビ+マウス
* `SYSTEM_LAYER`(3): BT/メディア/明度/ボリューム

### 1-2. カスタムbehavior一覧

| 名前 | 種類 | 用途 | 移植要否 |
| --- | --- | --- | ---- |
| `sticky_mod` | macro-one-param | hold時の遅延離脱付きMod | **要** (HRMの基盤) |
| `&mt` 上書き | hold-tap | hold=sticky\_mod, tap=kp | **要** |
| `&lt` 上書き | hold-tap | quick-tap-ms=200 | 不要（B1 Pro keymapで `&lt` 未使用） |
| `mt_tap` | hold-tap | hold=tap\_key (1tapを発火) | 不要（B1 Proに専用キー有） |
| `tap_key` | macro-one-param | mt\_tap の依存 | 不要 |
| `lm` | macro-two-param | layer + mod 同時発火 | 不要（該当comboを移植しない） |
| `mt2` | hold-tap | tap-preferred変種 | 不要（移植元でも未使用） |
| `tap_dance_layer_1and2` | tap-dance | mo1/mo2切替 | 不要（移植元でも未使用） |
| `tp_msc_*` / `tp_mkp_*` | tap-dance | スクロール/マウスボタン | 不要（B1 Proにマウス機能なし） |
| `zip_dyn_scale*` | カスタム | トラックパッドDPI | 不要（B1 Proに該当機能なし） |

### 1-3. HRM (Home Row Mod) 一覧

| 位置 | キー | hold | 種別 |
| --- | --- | ---- | --- |
| 0 | Q | ESCAPE | mt\_tap (専用キー有のため移植せず) |
| 1 | W | LGUI | mt (HRM) |
| 3 | R | INT4 | mt\_tap (専用キー有のため移植せず) |
| 10 | A | LCTRL | **mt (移植対象)** |
| 11 | S | LALT | **mt (移植対象)** |
| 13 | F | INT5 | mt\_tap (専用キー有のため移植せず) |
| 20 | Z | LSHIFT | **mt (移植対象)** |
| 22 | C | CAPSLOCK | mt\_tap (専用キー有のため移植せず) |

### 1-4. Combo一覧

| 名前 | 位置 | 動作 | 移植要否 |
| --- | --- | --- | ---- |
| CONBO\_ESC | 0+1 (Q+W) | ESC | **要** (B1 Pro 30+31 へ) |
| COMBO\_TAB | 10+11 (A+S) | TAB | 不要（B1 ProにTAB専用キー有） |
| COMBO\_TAB\_ALT | 33+4 (mo2親指+T) | lm 2 LEFT\_ALT | 不要（60%親指キー依存） |

## 2\. B1 Pro JIS で維持する設定（既存）

* F-row全体（ESC, F1-F12 機能, DEL）
* 数字行（GRAVE, 1-0, -, =, INT3, BSPC）

* 親指列（LCTRL, LWIN/LALT, LCMD/LALT, LANG2, SPACE, LANG1, RCMD/RALT, FN, 矢印）
* 既存の `mo 1` / `mo 2` / `mo 3` レイヤー切替構造 (Mac default → Mac Fn → Win default → Win Fn)

* モード切替行 (mo2, OUT\_BLE, OUT\_24G, OUT\_CHG, OUT\_CHGD)
* `keychron_b1_jis.conf`（変更なし、ハードウェア依存設定はLalaPadGen2と無関係）

## 4\. 確認事項（要回答）

### Q1. Mac layer の HRM 修飾キーの方向性

* 案A（**現方針**）: LalaPadGen2と同じ `LCTRL / LALT / LSHIFT`
* 案B: Mac慣習に合わせ `LGUI(LCMD) / LALT / LSHIFT`
=> 案A

### Q2. Win layer の HRM 修飾キー

* 案A（**現方針**）: Macと同じ `LCTRL / LALT / LSHIFT`
* 案B: 別構成
=> 案A

### Q3. Q+W=ESC combo の有効レイヤー

* 案A（**現方針**）: `layers = <0 2>` (Mac default + Win default のみ)
* 案B: 全レイヤー
* 案C: 不要
=> 案B

### Q4. tapping-term-ms / quick-tap-ms / require-prior-idle-ms

LalaPadGen2は `&mt` の tapping-term は明示せずZMK標準(200ms)依存、`quick-tap-ms = <0>`。

* 案A（**現方針**）: LalaPadGen2踏襲
* 案B: 別の値 (例 `tapping-term-ms = <200>; quick-tap-ms = <175>; require-prior-idle-ms = <125>;`)
=> 案A

### Q5. その他、移植したい項目があれば

=> もうB1PROのOS切り替え機能はなくしちゃっていいです。lalapadの０１２３レイヤーをそのまま０１２に割り当てましょう。
3に関してはシステム系なので一旦スキップしましょう。

## 5\. ビルド時の注意点

1. `&mt` 上書きは `/` ノードの外（ルートスコープ）に記述する必要あり。LalaPadGen2と同じ書式で配置。
2. `sticky_mod` ラベルは B1 Pro 既存keymapで未使用 → 衝突なし。
3. 新combo は既存 `combos1` ノード内に追記（`compatible = "zmk,combos"` の同居OK）。
4. `&mt LCTRL A` 等の bindings は ZMK標準。`&kp` 互換のためビルドエラーにならない。
5. matrix transform は変更しないため、キー位置インデックス (0-85) は維持。
6. `keychron_b1_jis.conf` 無変更 → 既存build artifact構成と互換。
